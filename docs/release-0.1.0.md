# Scriblism v0.1.0

首個公開版本，適用於 Windows 11 24H2（build 26100）以上的 x64 電腦。下載 `Scriblism.Setup.exe` 執行安裝；安裝程式會依電腦環境使用共用或自帶的 Windows App 執行環境。

## 這版包含

- WinUI 3 原生文字編輯器，支援多文件分頁、檔案側邊欄、Markdown 大綱與 33 種語言／格式選項。
- Markdown 同區即時排版與原始碼切換；搜尋、取代、復原、重做和未儲存內容復原。
- UTF-8、UTF-16／32 與 LF／CRLF／CR 讀寫；儲存前檢查磁碟上的檔案是否已變更。
- 單檔圖形化安裝程式，可在目前使用者帳號安裝、更新或解除安裝。

## 已知限制

Markdown 表格與圖片保留原始語法，不顯示成表格或內嵌圖片；沒有 LSP、自動完成或外掛。文件大小上限 16 MiB，超過 262,144 個 UTF-16 字元時停用語法高亮和行號。安裝檔尚未簽章。
