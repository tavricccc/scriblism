文字、程式碼，
都在同一處。

Scriblism 是 Windows 11 原生編輯器。開啟資料夾，就能在 Markdown、程式碼與純文字檔案之間切換，接著寫下去。

下載 Windows 安裝程式 安裝前先看 ↗

Windows 11 24H2 以上 · x64

專心寫眼前的檔案。

開啟資料夾後，從側欄找檔案，再用標題列的分頁切換。編輯區保留給文件，不讓工具列佔去位置。

Markdown 保留原文

按 Ctrl+E 切換原生預覽與原始碼。預覽支援標題、連結、圍欄程式碼和表格；點選區塊可回到對應的 Markdown 原文。

程式碼，輕鬆編輯

語法上色、行號、自動縮排，以及搜尋取代，足以處理日常修改。可選擇 33 種語言與格式。

文字留在這台電腦

未儲存的內容會在輸入暫停後備份到本機。意外關閉後可選擇復原；若檔案已被其他程式修改，儲存前會提醒。

儲存時，也照顧細節。

Scriblism 保留支援的 Unicode 編碼與換行方式。儲存時先寫入暫存檔，再取代原檔；若磁碟上的內容已改變，會先提醒。

下載，打開檔案。

從 GitHub Releases 下載 Scriblism.Setup.exe，執行即可安裝或更新。安裝只套用至目前使用者，不需要管理員權限。
