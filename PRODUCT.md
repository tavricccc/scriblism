# Scriblism

<!-- impeccable:product-schema 1 -->

## Platform
Windows desktop (WinUI 3; not a web application).

## Stack
User-confirmed: native WinUI 3, including the editor. No WebView2, Electron, or plug-in system. Independent sibling of Peeklism; reuse suitable patterns without modifying Peeklism.

## Product Purpose
A lightweight editor for code and Markdown, with a file-manager sidebar. Code highlighting follows the breadth of Notepad++; Markdown editing follows the in-place experience of Typora and Obsidian. Some VS Code navigation conventions, without a full IDE.

## Brand Commitments
Name: Scriblism. Preserve the native Windows / Fluent visual language of Peeklism.

## Operating Context
Windows 11 desktop. Traditional Chinese is the initial interface language, inferred from the conversation rather than a permanent localization constraint.

## Implementation authority
The user asked to continue through working implementation and verification without waiting for optional decisions. Audience details, licensing, commercial distribution, update endpoints and non-Markdown rich-text storage formats remain undecided. Do not fabricate them.

## Product Principles
- Preserve the user's text and explicit save decisions.
- Use native input, focus, accessibility and window conventions.
- Editing and navigation take priority over IDE features.
- Document limitations rather than presenting a prototype capability as complete.
